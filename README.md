# כרמי גת — מערכת מעקב, שליפה שעתית והתראות טלגרם לדירות להשכרה 🏢

מערכת Fullstack מתקדמת שנבנתה ב-**Next.js 15 (App Router)**, **PostgreSQL 16**, **Prisma ORM**, **Docker Compose** ובוט **Telegram**.  
המערכת שולפת אוטומטית בכל שעה את כל מודעות הדירות להשכרה בשכונת **כרמי גת** בעיר **קרית גת** מאתר [Realta](https://realta.co.il/he/), מדמה את כפתור "טען עוד" (Load More) עד למיצוי מלא של כל המודעות, מונעת כפילויות במסד הנתונים, שולחת התראות מיידיות לטלגרם, ומאפשרת ניהול סטטוסים, כתיבת הערות אישיות ותזכורות חכמות.

---

## 🌟 פיצ'רים מרכזיים (Features)

1. **שליפה שעתית אוטומטית (Hourly Scraper)**:
   - סריקה מתוזמנת בכל שעה עגולה באמצעות `node-cron`.
   - מימוש מלא של דפדוף "טען עוד" (כל המנות עד למיצוי 100% מהתוצאות).
   - חילוץ נתונים מקיף: מחיר חודשי (₪), מספר חדרים, שטח (מ״ר), קומה מתוך קומות, כתובת/רחוב, מאפיינים (ממ״ד, חניה, מעלית, מיזוג), תמונות, מקור מודעה (יד2, מדלן, קומו וכו') וקישור ישיר למודעה.
   - כפתור "סנכרן עכשיו" בממשק לסנכרון מיידי בכל רגע.

2. **מסד נתונים ומניעת כפילויות (PostgreSQL & Prisma)**:
   - מזהה המודעה המקורי של Realta נשמר כ-Primary Key.
   - מניעת כפילויות מוחלטת: דירות קיימות מעודכנות בלבד (מחיר, תאריך עדכון), תוך שמירה מלאה על הסטטוס, ההערות ותאריכי החזרה של המשתמש!

3. **ניהול סטטוסים מתקדם (Status Workflow)**:
   - לכל דירה ניתן לקבוע סטטוס:
     - 🔹 **חדש (`NEW`)** — ברירת מחדל בעת גילוי ראשוני.
     - 🟢 **רלוונטי (`RELEVANT`)** — דירה מתאימה להמשך טיפול.
     - 🟡 **דרוש בדיקה (`NEEDS_CHECK`)** — נדרש בירור מול בעל הנכס/מתווך.
     - 🟣 **בדיקה בהמשך (`CHECK_LATER`)** — כולל בחירת תאריך ושעת חזרה!
     - ⚪ **לא רלוונטי (`NOT_RELEVANT`)** — הסרה מהתצוגה הפעילה.
   - סרגל לשוניות מהיר למעבר בין סטטוסים עם מונים חיים.

4. **כרטיסיית דירה, הערות ותזכורות מעקב**:
   - לחיצה על "פרטים והערות" פותחת חלונית מפורטת עם גלריית תמונות, מפרט מלא ותוספות.
   - אזור הערות אישיות לכל דירה עם שמירה מיידית.
   - בחירת תאריך חזרה למעקב — המערכת שולחת התראה בטלגרם בתאריך המיועד עם פרטי הדירה וההערות שלך!

5. **תזכורות עצמאיות (Independent Reminders)**:
   - אפשרות לקבוע תאריך ושעה לכל נושא עם הערה מוצמדת.
   - הבוט שולח הודעה לטלגרם במועד המדויק שנקבע.

6. **התראות טלגרם חכמות (Telegram Bot)**:
   - התראה על כל דירה חדשה שמתווספת בכרמי גת.
   - התראה על תאריך מעקב של דירה.
   - התראה על תזכורת כללית.
   - כפתור "בדוק חיבור לטלגרם" בממשק לשליחת הודעת ניסיון.

7. **דוקר קומפוז ופרודקשן (Docker Compose)**:
   - קונטיינר מסד נתונים `karmei_gat_postgres` (PostgreSQL 16) עם Volume קבוע.
   - קונטיינר אפליקציה `karmei_gat_app` (Next.js Standalone).
   - בדיקות בריאות (Healthchecks) מוגדרות לשני הקונטיינרים.

## 🚀 הפעלה והרצה מהירה (Quick Start)

### 1. שכפול המאגר (Clone Repository)
```bash
git clone https://github.com/<your-username>/findmyapprtment.git
cd findmyapprtment
```

### 2. הגדרת משתני סביבה
העתק את קובץ הדוגמה לקובץ `.env`:
```bash
cp .env.example .env
```
פתח את `.env` והזן את פרטי הבוט שלך (אופציונלי לקבלת התראות):
```env
TELEGRAM_BOT_TOKEN="your_bot_token_from_botfather"
TELEGRAM_CHAT_ID="your_chat_id"
```

### 3. הפעלת המערכת בדוקר (Docker Compose)
הרם את המערכת בפקודה אחת:
```bash
docker compose up -d
```

לאחר עליית הקונטיינרים:
- 🌐 **ממשק המשתמש**: פתח בדפדפן בכתובת [http://localhost:3004](http://localhost:3004)
- 🩺 **בדיקת בריאות שרת**: [http://localhost:3004/api/health](http://localhost:3004/api/health)
- 🗄️ **מסד נתונים PostgreSQL**: זמין בפורט `5434` (חיבור חיצוני: `localhost:5434`, משתמש: `postgres`, סיסמה: `postgres`, מסד: `findmyapprtment`).

### 4. הרצה מקומית ללא Docker (Development)
אם ברצונך להריץ את השרת ישירות על סביבת הפיתוח:
```bash
# 1. התקנת תלויות
npm install

# 2. סנכרון מסד הנתונים
npx prisma db push

# 3. הפעלת שרת הפיתוח
npm run dev
```

## 📊 בדיקת סטטוס ובריאות קונטיינרים

לבדיקת מצב הקונטיינרים וה-Healthchecks:
```bash
docker compose ps
```
פלט לדוגמה:
```
NAME                  IMAGE                 STATUS                        PORTS
karmei_gat_app        findmyapprtment-app   Up (healthy)                  0.0.0.0:3004->3000/tcp
karmei_gat_postgres   postgres:16-alpine    Up (healthy)                  0.0.0.0:5434->5432/tcp
```

לצפייה בלוגים חיים:
```bash
docker compose logs -f app
```

## 🧪 הרצת בדיקות אוטומטיות (Automated Tests)

המערכת כוללת בדיקות אוטומטיות מקיפות הבודקות:
1. שליפה מלאה מול Realta ודפדוף מנות (24 + מנות המשך).
2. אימות מניעת כפילויות במסד הנתונים.
3. פורמט הודעות טלגרם בעברית (דירה חדשה, תזכורת דירה, תזכורת כללית).

להרצת הבדיקות:
```bash
npm run test:ts
```
